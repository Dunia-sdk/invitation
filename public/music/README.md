# Music Placeholder

Place your Moroccan Andalusian / Oud background music file here.

Filename expected: `background.mp3`

Full path: `public/music/background.mp3`

The CONFIG.musicUrl in `src/config.js` points to `/music/background.mp3` by default.
You can use any royalty-free Moroccan traditional instrumental (Oud, Andalusian, etc.)
from sites like:
- pixabay.com
- freemusicarchive.org
- soundcloud.com (royalty-free section)

After placing the file, the music player in the bottom-right corner will work automatically.
